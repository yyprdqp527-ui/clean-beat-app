🔍 Debug Inspector - Badges System

1. Inspectez l'HTML de l'avatar avec un badge

Dans Chrome DevTools (F12), cherchez un avatar avec un badge :

  1. Cliquez droit sur l'avatar → "Inspecter"
  2. Cherchez les balises <span> avec des emoji (💀, ❤️, 🔍)
  3. Notez la classe CSS du span :

Options possibles :

  • ✅ class="avatar-emoji-badge" → Nouveau système (correct)
  • ❌ class="heart-badge" → Ancien système (ne devrait plus exister)
  • ❌ class="skull-badge" → Ancien système (ne devrait plus exister)

2. Vérifiez le DEBUG comment dans le code HTML

Cherchez dans le code source (Ctrl+U ou Cmd+Option+U) :

<!-- DEBUG p2: email=... suspicion_active=... -->

Ce commentaire montre si suspicion_active=True ou False

3. Testez avec Emma (house_id 150)

Emma a 4 suspicions actives dans la base de données :

  • house_id: 150
  • suspected_player_email: Emma
  • status: 'pending' ou 'awaiting_validation'

→ Elle DOIT avoir une loupe 🔍 sur son avatar

4. Cache navigateur ?

Videz le cache et rechargez :

  • Chrome/Safari : Cmd+Shift+R (macOS)
  • Firefox : Cmd+Shift+Delete
