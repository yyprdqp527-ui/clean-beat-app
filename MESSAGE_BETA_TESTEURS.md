### 🔧 Installation sur Écran d'Accueil

Pour une meilleure expérience (mode app native, sans barre d'adresse), installe l'app sur ton écran d'accueil :

#### 📱 **iPhone / iPad (Safari uniquement)**

1. **Ouvre le lien dans Safari** (important : pas Chrome)
2. Clique sur le bouton **"Partager"** (icône carré avec flèche vers le haut ⬆️)
3. Scroll vers le bas dans le menu
4. Sélectionne **"Sur l'écran d'accueil"** ou **"Add to Home Screen"**
5. Clique **"Ajouter"**
6. L'icône CleanBeat apparaît maintenant sur ton écran d'accueil ! 🎉

#### 🤖 **Android (Chrome)**

1. **Ouvre le lien dans Chrome**
2. Clique sur le menu **⋮** (trois points verticaux en haut à droite)
3. Sélectionne **"Installer l'application"** ou **"Ajouter à l'écran d'accueil"**
4. Confirme l'installation
5. L'icône CleanBeat apparaît maintenant sur ton écran d'accueil ! 🎉

#### 💻 **Ordinateur (Chrome, Edge, Firefox)**

1. Ouvre le lien dans le navigateur
2. Un bouton "Installer" apparaîtra dans la barre d'adresse
3. Clique dessus pour installer

### 🎯 Première Utilisation

1. **Ouvre l'app depuis l'icône** sur ton écran d'accueil (pas depuis le navigateur)
2. **Autorise les notifications** si ta une popup le demande (pour recevoir les messages même app fermée)
3. **Crée ton compte** ou rejoins une maison existante avec un code

### ✨ Fonctionnalités Principales

- 🏠 Créer ou rejoindre une maison familiale
- ✅ Gérer les tâches ménagères avec points
- 💬 Messagerie privée entre membres
- 🏆 Système de récompenses
- 📊 Statistiques et classements
- 👶 Gestion des enfants avec comptes dédiés
