# 🔗 Trouver Ton URL d'Application Render

## Étape 1 : Aller sur Render Dashboard

1. Ouvre https://dashboard.render.com
2. Connecte-toi avec ton compte

## Étape 2 : Trouver Ton Service

1. Tu verras la liste de tes services
2. Cherche **"clean-beat-app"** (ou le nom que tu as donné)

## Étape 3 : Copier l'URL

1. Clique sur ton service
2. En haut de la page, tu verras une URL qui ressemble à :
   ```
   https://clean-beat-app-XXXX.onrender.com
   ```
   ou
   ```
   https://ton-nom-de-service.onrender.com
   ```

3. **C'EST TON LIEN D'APPLICATION !** 🎯

## Étape 4 : Remplacer dans le Message

Dans le fichier **MESSAGE_BETA_TESTEURS.md** :

Remplace `[TON-URL-RENDER.onrender.com]` par ton URL complète.

Exemple :
```
Avant : [TON-URL-RENDER.onrender.com]
Après  : https://clean-beat-app-xyz123.onrender.com
```
