## 🎓 GLOSSAIRE

**Gamification** : Transformer l'app en jeu (badges, points, défis)  
**UX** : User Experience (fluidité, intuitivité)  
**Affiliation** : Commission sur ventes via liens  
**Freemium** : Gratuit de base + version payante premium  
**KPI** : Indicateurs clés de performance  
**Conversion** : % utilisateurs qui achètent/s'abonnent  
**Rétention** : % utilisateurs qui reviennent après X jours  
**ARPU** : Revenu moyen par utilisateur  
**DAU** : Daily Active Users (utilisateurs actifs/jour)
