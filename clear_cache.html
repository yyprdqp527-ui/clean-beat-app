🧹 Nettoyage Cache

Supprimer tous les fichiers en cache pour Dust

1 Vider le cache navigateur
Appuyez sur Cmd + Shift + R (Mac) ou Ctrl + Shift + F5 (Windows)
2 Supprimer les données du site
Outils développeur → Application → Clear storage → "Clear site data"
3 Désinstaller Service Workers
Outils développeur → Application → Service Workers → "Unregister"
4 Ou utiliser le bouton automatique
Cliquez sur le bouton ci-dessous pour tout nettoyer automatiquement
