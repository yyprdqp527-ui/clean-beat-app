🧪 Test du Flux d'Invitation - CleanBeat

ℹ️ Vue d'ensemble

Cette page permet de tester le nouveau système d'invitation des partenaires pour CleanBeat.

Objectif : Un utilisateur peut inviter un ou plusieurs partenaires via SMS. Les partenaires peuvent alors rejoindre la maison et commencer à jouer après avoir nommé leur maison.

👤 Rôle : Hôte

  • Possède déjà un compte
  • A créé une maison
  • Veut inviter des partenaires

🎉 Rôle : Partenaire

  • Reçoit une invitation par SMS
  • Nouveau sur la plateforme
  • Veut rejoindre une maison

1 Scénario : Inviter des Partenaires (Hôte)

📋 Étapes à tester

  1. Se connecter avec un compte existant
  2. Accéder à la page d'invitation
  3. Noter le code de la maison affiché
  4. Ajouter plusieurs partenaires (nom + téléphone)
  5. Envoyer les invitations SMS
  6. Vérifier le message de confirmation
URL : /invite_partner
Méthode : GET pour afficher, POST pour envoyer
🚀 Tester l'invitation 🔐 Se connecter d'abord
⚠️ Note : Les SMS ne sont pas réellement envoyés en mode développement. Ils sont simulés et affichés dans la console du serveur.

2 Scénario : Rejoindre une Maison (Partenaire)

📋 Étapes à tester

  1. Étape 1 : Entrer le code de la maison (6 caractères)
  2. Étape 2 : Donner un nom à la maison
  3. Étape 3 : Créer son compte (nom, email, mot de passe)
  4. Étape 4 : Vérifier le récapitulatif et valider
  5. Être automatiquement connecté et redirigé vers le menu
URL : /join_house
Méthode : GET pour afficher, POST pour créer le compte
🏠 Tester la rejointe
✅ Validation :
  • Le code de maison doit exister
  • L'email doit être unique
  • Le mot de passe doit faire au moins 6 caractères
  • Tous les champs sont requis

3 Cas de Test Recommandés

✅ Cas Positifs

  • Invitation d'un seul partenaire
  • Invitation de plusieurs partenaires
  • Rejoindre avec un code valide
  • Navigation avant/arrière dans le formulaire
  • Auto-connexion après inscription

❌ Cas Négatifs

  • Code de maison invalide
  • Email déjà utilisé
  • Mot de passe trop court
  • Champs vides
  • Format de téléphone incorrect

🎯 Cas Limites

  • Inviter le même numéro deux fois
  • Code avec majuscules/minuscules
  • Caractères spéciaux dans le nom
  • Très long nom de maison
  • Navigation directe sans SMS
