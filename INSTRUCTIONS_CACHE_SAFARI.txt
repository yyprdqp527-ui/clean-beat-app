═══════════════════════════════════════════════════════════
  🧹 SOLUTION COMPLÈTE - VIDER LE CACHE SAFARI
═══════════════════════════════════════════════════════════

Étape 1: Activer le menu Développement
   • Safari → Réglages (Cmd + ,)
   • Onglet "Avancées" (tout à droite)
   • Cocher ✅ "Afficher le menu Développement"

Étape 2: Vider les caches
   • Menu "Développement" → "Vider les caches"

Étape 3: Vider l'historique
   • Safari → "Effacer l'historique..."
   • Sélectionner "tout l'historique"
   • Cliquer "Effacer l'historique"

Étape 4: Fermer Safari COMPLÈTEMENT
   • Cmd + Q (pas juste fermer la fenêtre!)
   • Vérifier que Safari n'apparaît plus dans le Dock

Étape 5: Rouvrir Safari
   • Lancer Safari
   • Aller sur: http://127.0.0.1:8000
   • Vous DEVEZ voir le bouton ORANGE 🟠

  ℹ️  POURQUOI CE PROBLÈME?
═══════════════════════════════════════════════════════════

Safari est TRÈS agressif avec le cache pour la performance.
Il garde les pages HTML/CSS en mémoire même après F5.
C'est normal et ça arrive à tous les développeurs.

→ C'est pour ça qu'on utilise le mode privé pendant le dev!
